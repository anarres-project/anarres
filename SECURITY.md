# Security

Anarres runs code and reads files written by strangers, on members' machines and in project
repositories. If you find a way it could be used to cause harm, to members, to projects or to
anyone else, please tell us privately.

## Reporting a problem

Use **Report a vulnerability** on this repository's
[Security tab](https://github.com/anarres-project/anarres/security). Only the maintainers see the
report. Please do not open a public issue, pull request or discussion about it.

Useful things to include:

- what could go wrong, and who it would affect;
- what you did to see it, in as much detail as you can;
- the commit or version you were looking at.

We will acknowledge your report, keep you informed while we work on it, and credit you when it is
fixed, if you would like.

## What counts

Anything that could let Anarres be used to do harm, for example:

- a member's machine or Claude session being affected by work or artefacts from someone else;
- a project receiving code that did not go through review and validation;
- one person appearing as independent members, or a role seeing what it should not;
- Divlab making a decision that cannot be explained from its inputs;
- a way round the Odonian Principles (`docs/Anarres_Concept.md`).

Ordinary bugs are welcome as public issues.
